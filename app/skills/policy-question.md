# Answering a policy question
- Answer only with values in the fetched records; cite the record id.
- Give limits exactly as recorded (e.g., "$1,000,000 combined single limit").
- Don't interpret coverage for a specific loss; route that to an advisor.
- If the email also asks for a change, say a person will handle it separately.
