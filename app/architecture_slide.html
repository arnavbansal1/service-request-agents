Architecture · multi-agent, code-enforced

Four bounded agents in a code-controlled workflow

Purple boxes are agents with bounded tools; gray is code, rules and data; green is a person. Two points to make: the LLM judge re-fetches its own evidence, so it can catch what the fulfillment agent left out; and agents never hold their own permissions. The orchestrator agent proposes the plan, but the workflow engine (code) decides which tools each agent may call and can override the plan, and nothing reaches a client without passing the gates and a person's approval.
